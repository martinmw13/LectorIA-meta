## 1. Provider switch: Muse Spark Open on Modal first, Meta API as fallback

A provider eval on the same task picked Muse Spark Open (Meta open weights,
`meta-models/Muse-Spark-Open-816B-A42B`) on a Modal Shared Endpoint: 103/103
sections right, about 2x faster than the Meta API, cents per book. Shared
Endpoints bill per token, so there is no idle cost. It is OpenAI-compatible
and accepts the same body (json_schema strict, reasoning_effort "low").

- pipeline/meta.ts: `createMetaClient` takes optional `url` (default the
  current META_URL) and optional `provider` label; nothing else changes, so
  existing callers and tests stay as they are. Error messages must not say
  "Meta" when the provider is Modal (use the label).
- pipeline/prices.ts: add Muse Spark Open shared-endpoint prices
  (USD per 1M: prompt 1.25, cached 0.15, completion 4.25) and a
  `costUsdFor(model, usage)` (or equivalent) so the judge reports the right
  cost per provider. Meta prices unchanged.
- pipeline/clean-judge.ts: `createCleanJudge(primary, fallback?)`: call
  primary; if it throws or returns invalid data, call fallback once. The
  JudgeResult/report llm block records `provider` ("modal" | "meta"),
  `model`, tokens, cost, and `fallbackUsed: boolean`. Never put raw error
  text in the report.
- One factory used by both pipeline/clean-epub.ts and pipeline/build.ts
  (e.g. `pipeline/clean-providers.ts`): reads env only.
  * Modal is used when `MODAL_CLEAN_URL` (full chat-completions URL, not
    secret) and `MODAL_CLEAN_TOKEN` (bearer token) are both set; model
    `process.env.MODAL_CLEAN_MODEL ?? "meta-models/Muse-Spark-Open-816B-A42B"`.
  * Meta is used when `META_API_KEY` is set; model
    `process.env.CLEAN_MODEL ?? "muse-spark-1.3-contributor"`.
  * Both set: Modal primary, Meta fallback. Only one: that one alone. None:
    throw `no cleaning LLM configured (set MODAL_CLEAN_URL+MODAL_CLEAN_TOKEN
    or META_API_KEY)`. `--no-llm` never reads any of these.
  * Test it with a fake env object (inject env as a parameter).
- Document in docs/tasks/24-cleaning.md and docs/contracts/cleaning.md:
  provider order, env names, how to create the endpoint
  (`modal endpoint create --shared --name lectoria-clean --model
