# Review 14: zod security override

Grok Bot review. Dependabot alert #1 (high): zod can exhaust memory while
validating oversized constrained collections; patched in 4.6.6.

zod is transitive only (@vercel/blob → @vercel/oidc → @vercel/cli-config,
which pins 4.1.11 exactly, also in its latest 0.3.4), so a direct bump is not
possible. Added `overrides: { zod: "^4.6.6" }`; lockfile resolves 4.6.7. No code
change, no Muse run.

Exposure note: our own code does not use zod. `POST /api/images` (the only
public POST route; `/api/health` is GET) parses with a hand-written
`parseImageRequest` after `await req.json()`, with no app-level body-size cap.
Only Vercel's platform limit (4.5 MB request body for functions) applies. Not
redesigned here; a cheap follow-up is to reject on `content-length` or read at
most a few KB before parsing.

Checks run locally: typegen, typecheck, hooks, 264 tests, build, check:size,
check:isolation, check:secrets --all, gitleaks. Verdict: clean, merge when CI is green.
