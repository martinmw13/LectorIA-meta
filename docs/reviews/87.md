# Review 87: distinct image styles

One Muse round (muse-spark-1.3), no fixes needed.

- The six owner-approved presets (denslow, watercolor, pen-pencil, comic, graphite, lantern-dusk) live verbatim in `core/style-prompts.ts`. Prompts run STYLE lead, composition, CONTENT, bookmap reference, STYLE REMINDER, then guards. That's the order that won the live test.
- Each preset has an extra `page` field: chapter-only cues for panel borders, such as "Panel borders drawn freehand in pencil." Scene images have no panels, so the field stays out of the scene prompt.
- Graphite is monochrome, so colour words are stripped from its reference. Otherwise "blue-and-white gingham" leaks colour into a grayscale page.
- The default style on Oz uses the Denslow preset. The default on other books keeps the generic "Classic book illustration" line, because the Denslow lead names the Oz plates. Oz guards (silver shoes, nothing from the 1939 film) appear only on Oz. Other books get "faithful to the text and period".
- The preset prompts name their references, such as Marvel, Spirited Away and Rackham. User custom text still goes through the same DENY list. A test checks that "marvel", "ghibli", "studio" and "in the style" are rejected.
- The `..` double period is gone: `sentence()` adds a period only when one is missing.
- The keys move to v5/c5. A sha256 lock test over the preset texts and sample prompts fails on any prompt text change until the versions and the hash are bumped.
- Pregen and the route stay byte-identical (parity tests).
- Cost: v5/c5 orphan the cached v4/c4 Oz images. They regenerate on demand or by a pregen run, which is not part of this task.
