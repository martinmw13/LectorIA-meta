One round each for server (A) and client (B). Fixed directly by Grok Bot:

1. **A stream with no usage block refunded the whole reserve.** The
   settle step did `0 - reserved`, so an answer that streamed but never
   reported usage cost nothing against the cap. It now keeps the reserve.
2. **A Redis failure between the two spend reserves leaked the first.**
   The outer catch refunded quota only. The reserve block now refunds
   everything it took before answering `unavailable`.
3. **Stopping early left the upstream call open.** The streamer's
   `finally` now aborts its controller when the consumer returns.
4. **Turnstile pointed at a non-existent endpoint.** Fixed to
   `/turnstile/v0/siteverify`.
5. **Bubble mirrored the wrong way (Martin).** The tail now sits bottom
   right, coming from the right margin, in all six skins. The art moved
   to `app/chat/chat-bubble.tsx` and the send arrow into the icon
   registry, which also fixed the inline-SVG guard test.
6. **The key step was unstyled in the panel.** `home-bring.css` loads on
   the home page only, so `chat.css` restyles the field and makes the
   action boxless.
