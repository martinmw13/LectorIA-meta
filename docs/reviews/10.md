## Muse review, round 1

Read the full `origin/main..ui-english` diff plus the spec, the three fix
prompts, and the Grok review above. Ran `npm test`: 27 files, 237 tests,
all green. No code edited, no server started.

What holds: selection is style-only with no mode, soundtrackId, or mix
path; no-immediate-repeat, same-emotion cycling with fallback, history
pop with restart-on-empty (including Chopin mode), and the manual hold
all have tests that pin the behaviour. The now-playing line renders
`display title · composer · source` from `nowPlaying(track)` on every
`currentId` change with the full credit in the tooltip. Prefs ignore
unknown and obsolete fields, keep a valid style, and fall back to 0.8
volume. Picture requests send ordinals and ids only, never text; the
popover needs 3 chars inside the scene, hides on outside click, Escape,
page or scene change, request start, and while loading. No new
endpoints, no secrets, no raw errors to clients. No Spanish UI remains
(the only accented words are manifest track metadata in test fixtures,
which the converter owns). `public/music`, the converter, and the CSP
are untouched; only `public/art` was added, as fix round 2 required.

1. (Should) Contracts still promise the deleted hysteresis.
   `docs/contracts.md` says a track switches "only when it beats the
   current score by `switchMargin`" with a hard cut at `hardCutMargin`
   ("1.5 s for hard cuts"). The code deleted `gatedEvaluate`, so
   scheduled selects use only the random draw within `randomTolerance`
   plus the min-track hold. Rewrite that paragraph to describe the draw.
2. (Should) Contracts misstate the player props.
   It says `app/player.tsx` takes "the scene title, a skip flag, and
   callbacks". The component takes `track`, `replayNonce`, `fadeSec`,
   `canPrev`/`canSkip` with handlers, volume, mute, styles, and playlist
   props, and no scene title. Update the sentence to match.
3. (Nit) `persist` in `app/reader.tsx` takes a `sound` argument nothing
   passes; the one caller sends style only. Drop the parameter and read
   the refs inside.
4. (Nit) `hardCut` is now always false and `switchMargin`,
   `hardCutMargin`, `hardCutCrossfadeSec` have no readers. Harmless, but
   name them as kept-for-later or remove them.
5. (Nit) The reader parses localStorage three times on mount: twice in
   the volume and mute initializers and once when the manifest lands.
   Read once into a single initial value.
6. (Nit) Double-clicking "Picture scene" while loading starts a second
   poll loop of up to 2 minutes; `request` has no loading guard. Ignore
   the click while `card.phase` is loading.

Verdict: changes needed
