# Review 53: continuous scroll reader

## What changed

- `app/leer/book-view.tsx` (new, replaces `scene-page.tsx`): whole
  book as one column; chapter headers with panels strip inline;
  per-scene sections; one IntersectionObserver for the scene in view;
  URL via `replaceState`; native keys; pager/chapter-jump scrolling.
- `app/leer/[sceneId]/page.tsx`: builds the whole-book view once, no
  `key={sceneId}` remount.
- `app/reader.tsx`: live scene id from the store, route id fallback;
  chapter jumps dispatch a scroll event.
- `app/leer/scroll-helpers.ts` + test, `app/leer/current-scene.ts`:
  scene picking, section jumps, narration `followIntoView`.
- `app/folio/use-pictures.ts`: cache resync on scene change,
  stale-poll guard, `rescan` for cross-scene selections.
- Deleted: `scene-page.tsx`, `scroll-turn.ts` + test, paged helpers in
  `core/reader.ts` + their tests, `pageOfOrdinal` + its test.
- CSS: section `content-visibility`, break ornament, dead cover/end
  rules out, lazy images on figures/vault/panels.
- `scripts/e2e-scroll.py` rewritten; `check-isolation` checks
  whole-book routes; `docs/contracts/{scene-reader,chapter-panels,
  music-session}.md` updated.

## Decisions

- `replaceState` plus a tiny store instead of `router.push`: scrolling
  never remounts; App Router state may not follow `replaceState`, so
  the store (not `useParams`) drives music, pictures, and pager.
- Max-ratio picking with document-order ties: stable at 50/50
  boundaries, URL moves monotonically while scrolling.
- Unlock-on-passing for chapter panels preserves the old end-page
  semantics without an end page.
- Frames render inline per scene from the current scene's figure
  cache; scrolling back restores them from the session cache.

## Risk

- p95 frame time (33.4 ms) sits just under the 34 ms budget in
  headless SwiftShader rendering; real GPUs should do better, but a
  slower machine could cross it.
- `replaceState` per scene leaves App Router state behind the URL;
  anything that later reads `useParams` for the scene (only the
  first-load fallback does today) must use the live store instead.
- `content-visibility: auto` estimates offscreen section heights;
  fast programmatic jumps land correctly (forced render), brief
  scrollbar thumb jitter is possible.
