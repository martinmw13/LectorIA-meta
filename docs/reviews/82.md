# 82 review: chapter panels

One Muse round. Fixed directly by Grok Bot:

1. **The pregen script skipped the daily cap.** It reserved the daily
   counter but never checked it, so a long run could pass
   `DAILY_SPEND_CAP_USD`. It now stops and refunds both reserves at
   either cap, like the route does.
2. **Wait caption rebased onto the shared one.** Main moved the picture
   wait line under the frame as `PictureWait`. The modal now uses it
   instead of a private `panels-wait` line, so all pictures look the same
   while they load.

Checked: scene and passage keys are unchanged (tests pin them), chapter
keys carry their own `c1` prompt version, the client sends only the
chapter number, a cache hit uses no quota, and a miss counts 1 picture.

Open:

  in view this visit). The server only checks that the chapter exists,
  because it does not know how far you have read.

  That is why the captions sit under the page and not on top of it.
