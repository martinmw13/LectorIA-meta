# Review 20: home page, client-side EPUB parsing, free/BYOK upload flow

## Grok Bot review (round 0, before the Muse review)

Diff `origin/main...home` read by hand, rebased on 62c7f35. Local build,
323 tests, hooks, isolation, secrets and size all green. Clicked through a
local `next start` with real Gutenberg EPUBs (Alice, Oz, Moby-Dick), a
text file renamed `.epub`, and Alice with a `META-INF/rights.xml` added:
every state renders, `/read/oz` and `/` -> Start reading land on
`/leer/c1s1` with music playing.

1. Must: home links have no colour rule, so they use the browser default
   blue and turn purple once visited. Colour every link in `.home-root`
   with `--color-accent` (visited too), `--color-accent-hover` on hover.
2. Must: buttons and inputs do not inherit the UI font (the disabled
   "Read with soundtrack" renders in Arial). `font: inherit` for
   button/input inside `.home-root`.
3. Must: the hero hardcodes Oz's image path, so a new manifest book cannot
   get its art without a UI change. Add a `cover` path to the manifest
   entry (validated as a string starting with `/art/`) plus `coverAlt`,
   and use them in the hero.
4. Should: Gutenberg EPUBs list front matter as chapters ("Alice's
   Adventures in Wonderland", "THE MILLENNIUM FULCRUM EDITION 3.0",
   "Contents"; Moby-Dick: "ETYMOLOGY.", "EXTRACTS."). Drop labels equal to
   the book title (case and punctuation insensitive), "Contents"/"Table of
   Contents", and any containing "Project Gutenberg". Test it. Keys in the
   card use the label, which can repeat: use the index.
5. Should: spacing. The BYOK block sits on the book card with no gap, and
   the small print reads as one grey block. Give the card and BYOK step
   `--space-lg` between them, group the small print with less inner gap.
6. Nit: BookCard recomputes pages; use `approxPages`. ByokStep's unmount
   `setKey("")` does nothing (state is gone on unmount); drop it.

Security read: the key lives only in React state, `type=password`,
`autoComplete=off`, no storage, no logging, no network call. EPUB text
renders through React only, no `innerHTML`. The inflate filter caps each
entry at 8 MB before inflating and the total at 60 MB. `jsdom` is a
devDependency only; `fflate` 0.8.3 pinned.
