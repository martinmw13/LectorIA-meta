## Findings

1. **Large binary files are wrongly blocked** (`scripts/check-file-size.mjs:110-123`), blocker.
   - **What this is:** the size check asks git which staged files are binary, then skips them.
   - **Problem:** it parses `git diff --numstat -z` as `counts, path` pairs. The real record shape is `added, deleted, path` in one NUL-terminated chunk, and renames add two extra chunks (`od -c` proof in finding detail). I staged a 21 KB random binary and the script blocked it with exit 1. It should have skipped it.
   - **Fix:** parse each NUL-separated chunk with `/^(\d+|-)\t(\d+|-)\t([\s\S]*)$/`. An empty path means a rename lead, so skip the next chunk (old name) and key the map on the chunk after it (new name). Export the parser as a pure function and add a unit test with a binary record, a rename record, and a path with a space.
   - **If we skip it:** the first committed PNG, font, or fixture over 20 KB fails the hook, and the secret scanner path is unaffected only by luck (it reads blobs directly).

2. **package.json is one line** (`package.json:1`), should-fix.
   - **What this is:** the manifest holds the right keys and scripts.
   - **Problem:** the whole file is a single line. The review spec asks for normal 2-space formatted JSON, and one line makes diffs unreadable.
   - **Fix:** run `node -e "const fs=require('fs');fs.writeFileSync('package.json',JSON.stringify(require('./package.json'),null,2)+'\n')"` and confirm `npm run test:hooks` still passes.
   - **If we skip it:** every later key edit rewrites the whole line.

3. **History scan mislabels deleted files** (`scripts/check-secrets.mjs:162-169`), nit.
   - **What this is:** `--all` mode attributes added lines to the file named by the last `+++ b/` header.
   - **Problem:** for a deleted file the header is `+++ /dev/null`, which the parser ignores, so its lines keep the previous file name in the report. Findings still print, only the path is stale.
   - **Fix:** reset the label to the `--- a/` path when `+++ /dev/null` appears, or label it `<deleted>`.
   - **If we skip it:** a rare confusing path in a history report.
